# ỨNG DỤNG BÁN NỘI THẤT TÍCH HỢP 3D & AR

## 1. Giới thiệu đề tài

Dự án xây dựng ứng dụng bán nội thất trên nền tảng Android, giúp khách hàng tìm kiếm, tham khảo và lựa chọn các sản phẩm nội thất thuận tiện hơn thông qua điện thoại.

Điểm nổi bật của ứng dụng là khả năng **trình chiếu mô hình nội thất 3D và trải nghiệm thực tế tăng cường (AR)**. Khách hàng có thể quan sát sản phẩm từ nhiều góc độ và thử đặt sản phẩm vào không gian thực để hình dung cách bố trí trước khi quyết định mua.

Dự án được thực hiện bởi nhóm 3 sinh viên, sử dụng Android Studio làm môi trường phát triển chính.

## 2. Công nghệ sử dụng

| Công nghệ                            | Mục đích                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------- |
| Android Studio                       | Môi trường phát triển ứng dụng Android                                    |
| XML Layout hoặc Jetpack Compose      | Xây dựng giao diện Android; nhóm sẽ thống nhất một hướng triển khai chính |
| Thư viện hiển thị 3D                 | Đang nghiên cứu, lựa chọn theo khả năng tương thích                       |
| ARCore hoặc giải pháp AR tương thích | Nghiên cứu và thử nghiệm chức năng thực tế tăng cường                     |

Công nghệ lưu trữ dữ liệu và backend sẽ được xác định trong quá trình phân tích yêu cầu.

## 4. Hướng dẫn chạy dự án

1. Cài đặt Android Studio và Android SDK phù hợp.
2. Clone repository về máy tính.
3. Mở thư mục project bằng Android Studio.
4. Chờ Gradle Sync hoàn tất.
5. Chọn Android Emulator hoặc kết nối điện thoại Android đã bật USB debugging.
6. Nhấn **Run** để biên dịch và chạy ứng dụng.

Các yêu cầu riêng về thiết bị, SDK và thư viện 3D/AR sẽ được cập nhật khi nhóm chốt công nghệ.

## 5. Quy ước làm việc nhóm

- Mỗi thành viên phát triển trên nhánh riêng.
- Không commit trực tiếp lên nhánh `main`.
- Đặt tên nhánh theo chức năng hoặc tên thành viên, ví dụ `feature/dat`, `feature/vinh`.
- Commit với nội dung ngắn gọn, mô tả đúng thay đổi.
- Push nhánh lên GitHub và tạo Pull Request để review.
- Chỉ merge sau khi đã kiểm tra thay đổi và xử lý xung đột.

## 6. Trạng thái dự án

Dự án đang trong giai đoạn phân tích, hoàn thiện thiết kế và phát triển phiên bản đầu tiên. Các chức năng sẽ được cập nhật dần theo tiến độ thực hiện.
